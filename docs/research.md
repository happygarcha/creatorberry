# Inspiration research

Sources were read as text only, so colours and fonts are not taken from them.

| Site | Use for Drapewell |
|---|---|
| modulify.ai/templates | Layout ideas from ecommerce templates (preview-first cards, category chips). Not a Shopify theme source. |
| motionin.design | Shoppable "buy the whole look" panels, mood/category tiles, zoom-from-thumbnail galleries, scroll-driven heroes. Avoid heavy WebGL/canvas effects. |
| landdding.com | Gallery with E-commerce and Furniture & Interiors filters; browse for structure references. |
| 60fps.design | Mobile interaction ideas: bottom-sheet variant picker, shared-element image transition, toast on add to cart, skeleton loading, subtle stagger/parallax. |
| footer.design | Large-type wordmark footers, grid-style link groups. |
| recent.design | General inspiration feed; low value for footers. |

## Guardrails
- Mobile first; keep motion light and fast.
- Respect `prefers-reduced-motion`.
- No heavy 3D/canvas in the main path.
